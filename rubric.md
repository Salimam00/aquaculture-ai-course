# Analytical rubric

Each practical work is scored from 0 to 16.

| Criterion | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| Code correctness | absent | does not run | runs with major help | runs with minor fixes | fully reproducible |
| Method choice | absent | incorrect | partly justified | correct | compared with alternatives |
| Interpretation | absent | incorrect | generic | domain-specific | includes uncertainty and risk |
| Documentation | absent | incomplete | basic | clear | enables independent reproduction |

Convert to 100 points as `score / 16 × 100`. Two assessors independently score a calibration sample; report inter-rater agreement before outcome analysis.
